### Project Highlights

- Led the development team by understanding client requirements, planning activities and assigning tasks.
- Worked with clients to translate business requirements into technical solutions.
- Coordinated Railway, Bus, Flight and Hotel module development.
- Developed reusable React components and responsive user interfaces.
- Built and integrated RESTful APIs using Node.js and Express.js.
- Implemented JWT-based authentication and authorization.
- Integrated Razorpay payment gateway.
- Implemented Twilio OTP verification and Nodemailer email notifications.

- Developed Admin Dashboard functionality for users, bookings, transactions and platform activities.
- Performed debugging, issue resolution and performance optimization.
- Reviewed code, guided team members and followed coding standards.
- Used Git and GitHub for version control and team collaboration.
- Worked with Docker and Kubernetes for containerization and deployment support.
- Followed Agile practices, sprint planning and project tracking.
- Coordinated frontend/backend integration and end-to-end functionality.
- Took ownership of technical challenges throughout the development lifecycle.

- Implemented CRUD operations for sellers and product data.
