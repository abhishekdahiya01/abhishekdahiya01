A multi-service travel booking and management platform covering Railway, Bus, Flight and Hotel booking modules. Responsible for coordinating development activities, understanding client requirements, implementing application features and supporting end-to-end integration.

### Key Responsibilities

- Led the development team by understanding client requirements, planning project activities and assigning tasks to team members.
- Worked directly with clients to understand business requirements and translate them into technical solutions.
- Coordinated the development of Railway, Bus, Flight and Hotel booking modules to ensure smooth integration across the platform.
- Developed reusable UI components using React.js and built responsive, user-friendly interfaces.
- Developed and integrated RESTful APIs using Node.js and Express.js for multiple application modules.
- Implemented JWT-based authentication and authorization for secure application access.
- Integrated Razorpay payment gateway for payment processing.
- Implemented Twilio OTP verification and Nodemailer email notification services.
- Designed, maintained and optimized MySQL tables, relationships and queries for application performance.
- Developed and managed Admin Dashboard functionality for users, bookings, transactions and platform activities.
- Identified and resolved bugs, performed debugging and optimized application performance.
- Conducted code reviews, guided team members and maintained coding standards.
- Used Git and GitHub for version control and team collaboration.
- Worked with Docker and Kubernetes for containerization and deployment support.
- Followed Agile development practices, participated in sprint planning and tracked project progress.
- Collaborated with frontend and backend developers for end-to-end integration and functionality.
- Took ownership of development tasks, resolved technical challenges and supported the team throughout the project lifecycle.

### Key Responsibilities
