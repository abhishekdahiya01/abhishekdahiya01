## About Me

I'm **Abhishek Dahiya**, a Full Stack Developer based in Bhopal, Madhya Pradesh, India.

I build modern web applications with a focus on responsive frontend interfaces, scalable backend systems, RESTful APIs, database design, authentication, and third-party integrations.

My development interests include:

- Full-stack web application development.
- REST API design and backend architecture.
- Relational and NoSQL database management.
- Secure authentication and role-based access control.
- Payment integrations and booking workflows.
- Application deployment and containerization.
- Retrieval-Augmented Generation (RAG) and AI-powered applications.

I enjoy solving practical problems through clean code, thoughtful architecture, and maintainable software.
